## [OpenAI 发布 GPT-6.1 Sol，API 价格仅为 Astra 的五分之一](https://openai.com/index/introducing-gpt-6-1-sol) ⭐️ 9.0/10

OpenAI 发布了 GPT-6.1 Sol，这是一款定位介于 GPT-6 Astra 与 GPT-6 Luna 之间的新模型，在编程、计算机操作和专业工作方面提供接近 Astra 的智能水平。该模型已通过 OpenAI API 以 gpt-6.1-sol 的名称开放使用，标准价格为每百万输入 token 2 美元、每百万缓存输入 token 0.10 美元、每百万输出 token 10 美元，但尚未在 ChatGPT 中上线。 通过以约为 Astra 标准 API 价格五分之一的价格提供接近旗舰级的智能水平，OpenAI 大幅降低了开发者构建智能体编程和计算机操作应用的成本门槛。这种定价压力可能重塑整个模型 API 市场的竞争格局，迫使 Anthropic、Google 等竞争对手重新证明自身性价比的合理性。 GPT-6.1 Sol 是 GPT-6 Sol 的升级版本，在智能体编程、计算机操作、专业工作和事实准确性方面均有提升。OpenAI 会自动缓存 1024 个 token 及以上的提示词，并且无论缓存前缀之后是否被再次读取，该模型都会对每次缓存写入计费。

rss · OpenAI Blog · 9月29日 10:00

**背景**: OpenAI 的 GPT-6 系列分为多个层级：GPT-6 Astra 是旗舰模型，被 OpenAI 称为其最智能、最对齐的模型，而 GPT-6 Luna 则位于 Sol 之下。GPT-6.1 Sol 是一款中端更新版本，以低得多的成本继承了 Astra 的大部分能力，并且通过 OpenAI API 而非 ChatGPT 消费端界面分发。报道中提到的“骑自行车的鹈鹕”测试，是 Simon Willison 推广的一种趣味性 SVG 生成基准，用于直观比较语言模型遵循空间与构图指令的能力。

一位化名 Faav 的 16 岁安全研究员发布了一份报告，详细说明他如何可能访问 17 万亿条微软记录，此前他 15 岁时曾发现微软访客签到系统中的 PII 泄露。该披露引发了社区对微软对报告编辑控制权以及仅 5000 美元赏金的争议。 此案凸显了安全研究员与大型厂商在协调漏洞披露、编辑控制权和公平赏金估值方面的持续紧张关系，这可能影响研究员的信任和整个安全生态。它还强调了在云服务中处理海量敏感数据时，JWT 等认证机制配置错误的风险。 该漏洞涉及一个算法设置为“none”的 JWT，这是一种已知但危险的错误配置，允许令牌伪造。据报道，微软对最终发布的文章拥有编辑控制权，删减了部分内容和图表，并重塑了影响描述。赏金为 5000 美元，评论者指出这远低于该项目最高 10 万至 25 万美元的奖励。

佛蒙特州部署了一个虚拟电厂（VPP），将特斯拉 Powerwall 等家庭电池聚合起来，以取代传统的调峰电厂，并已因此关闭了两座调峰电厂。参与者每月支付约 55 美元即可获得两块 Powerwall，并根据在停电和高需求时段向电网共享的储能电量获得电费减免。 这是虚拟电厂作为更便宜、更快速、更清洁的化石燃料调峰电厂替代方案的一次重要现实验证，而调峰电厂通常只在电力需求高峰时使用。如果该模式能够推广，它可能重塑公用事业规划发电容量的方式，降低用户成本，并加速分布式能源资源并入电网。 佛蒙特州的计划以每月约 55 美元的价格为每位参与者提供两块特斯拉 Powerwall，公用事业公司可以在停电或用电高峰时调度这些电池；北卡罗来纳州的类似计划则每月为每块电池支付约 50 美元，每年最多可调度 36 次。虚拟电厂将家庭电池和太阳能等小型分布式资源聚合起来，提供削峰等电网服务，相比调峰电厂可节省 40%至 60%的成本。

## [实时太阳系可视化：52.6 万颗小行星与所有在轨卫星](https://space.bl2.net/) ⭐️ 8.0/10

一位开发者发布了一个基于浏览器的实时太阳系可视化项目，以真实比例渲染了 52.6 万颗小行星和所有被跟踪的卫星，使用 WebGL2 和 Web Worker 实现。该项目每天从 CelesTrak TLE（SGP4）、JPL SBDB（小行星和彗星）以及 JPL Horizons（航天器位置）拉取数据，并提供一个可正反向运行的时间滑块。 这展示了浏览器图形和计算能力的巨大进步，使普通笔记本电脑也能实时模拟数十万个轨道物体。它让太空态势感知和轨道力学对任何拥有浏览器的人变得触手可及，同时也凸显了地球轨道上卫星密度不断增加的现状。 小行星数据集约 30 MB，在后台加载；轨道传播在 Web Worker 中运行，以保持界面流畅。卫星会根据发射日期出现和消失，模拟使用 SGP4 算法对 TLE 数据进行轨道传播。

hackernews · wanick · 9月29日 19:08 · [社区讨论](https://news.ycombinator.com/item?id=49898778)

**背景**: WebGL2 是一种无需插件即可在浏览器中渲染交互式 3D 图形的 JavaScript API，自 2022 年起已被所有主流浏览器支持。Web Worker 允许脚本在后台线程中运行，从而在不冻结界面的情况下执行轨道传播等计算密集型任务。CelesTrak 提供卫星的两行元素（TLE）数据集，SGP4 是传播其轨道的标准算法；JPL 的 SBDB 和 Horizons 则提供小行星和航天器的星历数据。
